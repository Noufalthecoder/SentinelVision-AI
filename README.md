# 🛡️ SentinelVision AI  
## Real-Time Computer Vision Surveillance & Restricted Area Monitoring System

An intelligent computer vision surveillance platform designed to detect unauthorized access in restricted zones using real-time object detection, video analytics, and automated alert mechanisms.

---

## 🚀 Overview

SentinelVision AI transforms traditional surveillance systems into an intelligent monitoring solution by combining deep learning-based object detection with real-time video processing.

The system continuously analyzes camera streams, identifies objects/persons entering restricted areas, and generates instant alerts for security monitoring.

---

## ✨ Key Features

| Feature | Description |
|--------|-------------|
| 🎯 Real-Time Object Detection | Detects objects and people from live video streams |
| 🚧 Restricted Area Monitoring | Identifies unauthorized entry into defined zones |
| 📹 Live Video Processing | Processes webcam/video feeds with low latency |
| 🔔 Automated Alert System | Generates alerts during security violations |
| 📊 Confidence Scoring | Displays detection accuracy levels |
| 🖥️ Interactive Dashboard | Provides simple monitoring and configuration interface |

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/Noufalthecoder/SentinelVision-AI.git
```

### Navigate to Project

```bash
cd SentinelVision-AI
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run streamlit_run.py
```
